# EVACTIS 3DWORKFLOW

Interactive digital environments of facilities — offline by design. Built by Evactis
(evactis.ca). *Safe plans. Clear paths.*

- **3DWORKFLOW Studio** — authoring (`apps/studio`)
- **3DWORKFLOW Viewer** — client player (`apps/viewer-desktop`, `packages/viewer` from Phase 2)
- **3DWORKFLOW Site Server** — optional, client-hosted (Phase 11)

Start with [CLAUDE.md](CLAUDE.md) (requirements, brand, phase checklist), then
`pnpm install && pnpm check`. Windows installers: [docs/windows-installers.md](docs/windows-installers.md);
IT deployment: [docs/it-deployment.md](docs/it-deployment.md).
